You have reached the 3D renderer version selector.
LEGACY is the old renderer, and only displays a ball. (Not recommended)
VOLUMES OF REVOLUTION is an updated renderer used for inputting up to two algebraic equations and rendering their revolution around the x-axis.
STAR PROJECTION is a functional but technically incomplete 3D renderer of star projection to Earth.
- Code for adding custom stars does exist, but it was never properly documented and no UI was ever made to support it (although it can still be done through the JS console).
- Has its own, more detailed, repository here.
